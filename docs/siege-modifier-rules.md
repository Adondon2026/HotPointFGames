# 拆家大战 v0.24 · 轻量炮击与连锁破坏

## 当前规则（v0.24）

保护己方核心，摧毁敌方核心。经典模式自选启用能力及开局稀有度；艺术就是爆炸采用固定主题权重、随机建筑及炸药桶。没有局内升级、拆除积分或拆除竞赛。

- 21 种能力，固定库存与单炮上限：分裂/连发/护盾 3；制导、修复、两个瞬移 1；其他 5。普通炮弹不限库存。负面每种每炮自动消耗一层，试验场可选择测试。库存满时道具原地保留，部分拾取后剩余份额保留。
- 分裂 n 层：出膛后一次展开为 2^n 枚，每枚直接伤害、冲击及攻击载荷力学强度乘 1/2^n；不递归分裂。连发 n 层额外 n 枚完整母弹。最多 4×8=32 枚。增大仅改变碰撞半径，破甲只针对石材等坚硬目标。
- 弹跳、穿透和制导能力不分层。所有实际碰撞（反弹、穿透、终点）自动释放对应效果，不配置触发时机。只有物理反弹才改变方向；分裂不赠送弹跳。爆炸主要提供外向冲击，黑洞提供内向吸引；推进沿射击方向作用。建造专用组合默认安全，不自炸核心；与攻击效果混合时保留攻击。
- 制导一次：飞行中点击世界目标，全体本方当前弹体向该目标转向；未发射的连发子弹也继承已执行的制导方向。不是持续锁定。真人不再使用折返、俯冲、反重力操纵和子弹时间。
- 技能单独使用：护盾/加固待对方攻击消耗，修复18点且最多1份，瞬移点击己方合法空地。无炮弹触发。
- 常见/进阶/稀有/珍贵权重8/4/2/1；开局只选等级，不填写概率。刷新点分开放空中、侧塔、中央塔，位置乘数不同。建筑被拆除后位置稀有度不变。主题预设的零权重项不出现。初始侧塔/开放资源镜像分配。
- 真实炸药桶碰撞受伤、受到爆炸或二次碰撞破坏后爆炸，每个仅一次，约0.08秒传播延迟，推动和伤害邻近物体。主题随机选择建筑模板、炮位和道具。当前物理仍是轴对齐矩形、质量与碰撞动能模型，尚无完整旋转刚体或像素级材料模拟。
- 新房间由新版客户端创建 v0.24 规则；存量旧对局继续旧规则以保证兼容，重新进入/开始新版对局。试验场自动迁移。所有其他游戏不变。

# 拆家大战 v0.23 · 飞行操纵与主题地图

## v0.23 修订（本节优先）

- 飞行操纵：折返、俯冲、反重力不再对真人自动按时间/顶点触发。开炮后点击对应动作，层数为本炮共享点击次数；单种时轻点战场亦可触发。动作分别反向水平速度、向下冲、向上冲；所有当前存活的本方弹体一起执行，不按分裂数量复制次数。未使用的次数退回库存。
- 子弹时间：1—5 层对应 0.9/0.8/0.7/0.6/0.5 倍速，点击后持续 1.2 秒现实时间，后续点击刷新。同步对射共用同一个权威物理时间轴；没有主动操纵的炮击继续使用原有回放。机器人仍使用既有自动运动逻辑。
- 反弹分裂：首次实际反弹先完成反射，约 0.1 秒模拟时间后按新运动方向释放子弹；其他反弹效果仍立即释放。五种触发方式保留。爆破改称爆破效果，爆破本身不终止弹体。
- 定时引信退出公开目录（35 种有效增益），旧库存转换为爆破；旧引擎直接调用保留历史回归兼容。
- 悬重堡垒（fragments）、露顶堡垒（peaks）、双层穿透堡（obstacle）、反射要塞（overtop）重做实体结构，保留 ID 和 11 张地图池。房间与试验场采用规模—具体地图分级选择。启用弹跳且非零道具时，初始道具优先保证弹跳；刷新兼顾地图主题与随机性，尊重房主禁用项。
- 火焰：燃烧每轮 14+4(n−1)，持续三轮；燃烧拖尾释放下落火星，接触木材引燃，遇石材停止。木质支撑烧毁后依照原有结构物理结算坍塌。
- 其余 v0.22 分裂继承、连发、统一事件载荷及生成上限保持不变。真实手机局域网延迟、长期性能及场景平衡仍需实战检验。

# 拆家大战 v0.22 · 统一炮弹规则

## 玩家规则

1. 战术储备：选择层数和事件效果的触发时机，右下角完成选择后才能开炮。自动模式按每种一层、默认时机执行。正式对战不提供完整轨迹预演，试验场提供。
2. 分裂 n 层：母弹消失，生成 n 枚子弹，基础伤害和冲击力各分配 1/n。子弹继承全部运动次数、属性、持续效果和事件载荷，但没有分裂、连发、玩家瞬移。分裂 1 层是一次弹道重构，并不增加弹数。
3. 连发 n 层：总计 1+n 枚完整母弹，连射或齐射；每枚均可独立分裂。母弹分裂前已发生的有效事件不撤销。
4. 复制、反弹复制、独立向下投弹不再是可选道具。分裂方向可选扇形、向下、散射；旧库存转换成分裂。
5. 每个事件载荷只有一个触发方式，不需要额外拾取触发器。

## 触发方式

| 时机 | 规则 |
|---|---|
| 出膛 | 每枚从炮口发射的母弹触发一次；分裂子弹不是再次出膛 |
| 顶点 | 每枚由上升转为下降时触发一次，没有顶点则不触发 |
| 反弹 | 每次真实地面、墙壁、建筑或反弹板反弹；不自带弹跳 |
| 穿透 | 每次对合格建筑成功判定穿透时触发；不触发终点 |
| 终点 | 正常碰撞结束飞行或引信引爆时触发一次；超时保护清理不算正常终点 |

碰撞顺序为有效穿透、有效反弹、结束飞行。普通墙体穿透优先于反弹。反弹板的固有反射不消耗普通弹跳次数。核心与固定平台不可穿透。
同一事件先执行其他绑定载荷，再执行分裂；母弹停止，子弹独立运动。终点分裂不额外释放母弹的默认终结爆炸。终点分裂时拥有穿透的子弹可以从碰撞点继续向建筑内部穿透。
定时引信改变结束条件，使用游戏内预设，不提供秒数输入。

## 增益分类与叠加

- 弹体与运动：弹跳、穿透、巨型、强力、破甲、冲击波、推进、螺旋、蛇形、俯冲、反重力、追踪、折返。子弹继承层数；伤害与冲击乘分裂分配系数。弹跳每层一次、穿透每层一个不同建筑。俯冲仍在顶点转向，折返仍采用现有固定时间间隔。
- 生成炮弹：分裂、连发。分裂一次，连发只在炮口执行，不递归。
- 事件载荷：分裂、爆破、木块、石块、地雷、黑洞、点火、克隆，共用上述五种时机。分裂默认顶点，爆破默认反弹，其他默认终点。
- 持续：燃烧拖尾、火焰连线、弹体护盾。火焰连线需要多弹，弹体护盾仅同步炮击有效，每枚子弹继承独立偏转额度。
- 玩家：护盾、加固、缓冲、修复、炮台瞬移、核心瞬移，不按分裂数量重复。
- 负面：重重、湮灭、不稳定、屁屁，仍按本炮生效。

爆破半径 38+9n+12×巨型层数，独立爆破伤害系数 0.45+0.12n，再乘本弹分配系数。点火伤害每轮 5+2(n-1)，持续两轮。黑洞每次生成一个场，层数增强其半径与强度。木块和石块每事件生成 n 个，安全建造不炸伤核心；攻击投放真实落下并可能损伤建筑。安全建造会暂停冲突的攻击效果，返还未投入库存。地雷、克隆为持续存在的战场实体，不分配生成数量。

## 统一容量与结算

| 对象 | 单炮限制 | 战场限制 |
|---|---:|---|
| 木块 | 24 | 木石合计存活生成块最多 60 |
| 石块 | 24 | 同上 |
| 地雷 | 12 | 每侧12，8炮后过期 |
| 克隆 | 12 | 每侧20，协射后续两炮，不递归造克隆 |
| 黑洞 | 12 个场 | 单炮上限，持续2秒 |
| 附属炮弹 | 120 | 单炮上限，不递归分裂 |

有多个有效事件时，材料及实体按发生顺序占用额度；实际消耗层数为 min(投入层数, ceil(实际生成数/有效事件数))，其余返还。黑洞一场使用投入强度，若无场生成则全额返还。未触发的分裂、爆破、点火等返还其投入。安全放置无合法空间时不生成。
例如十枚炮弹各请求5木块，理论50、上限24，若十个终点均发生则消耗3层，返还2层。试验场每炮补满库存，不需要计费。

## 验证与边界

测试覆盖首反弹分裂5枚、子弹反弹及穿透继承、无事件退款、反弹逐次触发、木块24上限与退款、连发逐弹分裂、同步弹体护盾、爆破半径、试验场路由与旧版回归。旧协议的直接引擎测试保留，公共游戏接口统一启用新版规则。
当前地图未重做，折返仍为原运动机制，安全建造按合法支持面落位。全组合平衡、真实手机长时间压力与新场景设计仍需继续验证。
