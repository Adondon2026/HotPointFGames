# 拆家大战：增益规则与组合契约（v0.21 体验修订）

## 游戏操作

玩家只需选增益数量、瞄准和开炮。每种增益有默认行为；有不同战术用途时用同一行的选项切换，不填写触发秒数、不打开二级参数窗口。分裂、复制等存在时，兼容“全弹/母弹/子弹”的行内作用域；分裂的二次分裂是可选项。旧版协议中的时间与独立子弹引信仍兼容，非新版默认操作。

## 全部 38 种增益

层数 n 为本次有效投入，不是库存总数。数值是当前实现的平衡起点；实际伤害会受碰撞、距离、防御、子弹系数影响。

## 组合优先级

1. 瞄准与出膛负面角度 → 自动运动（重力、顶点俯冲、追踪、折返、路径偏移）→ 真实碰撞。
2. 穿透优先于普通反弹；满足反弹条件才触发反弹复制/爆破。平台和反弹板遵循各自的地形规则。
3. 分裂、复制和连续弹是生成事件；新弹不能无限递归。可选二次分裂共享额外额度。修饰器作用域只改变被指定弹体的属性，材料及克隆只按实际投入生成。
4. 俯冲与反重力：上升由反重力控制，俯冲后恢复向下重力；俯冲与折返：俯冲以后停止定时水平折返；追踪可修正。
5. 安全建造暂停攻击性效果，不扣未生效增益。攻击投放保留普通伤害；生成材料按落点与合法空间结算。
6. 燃烧使用木材状态与回合结算，不按现实等待时间伤害。重复点火取较强的燃烧强度并续时；传播到新木块采用基础燃烧。
7. 正常房间的规则与试验场隔离。试验场目标始终满血，另记录潜在承伤；本方核心最低1血；防御可施加到靶场进行比较；库存每炮补满；不产生对局积分。

## 试验场验收

标准/近距/远距等11张地图可切换复原。对比相同角度力度与同一地图时的1层/5层，实际射击或“预演弹道”显示服务端模拟轨迹；预演复制战场、不扣库存、不推进回合。移动地图、随机负面及后续物理变化会影响预演与实射的吻合程度。

重点检查：俯冲1/5层、折返1/5层、反重力1–5层、反弹复制单独使用和配弹跳、分裂配火焰连线、向下投弹释放密度、建造配分裂、点火与拖尾、追踪配俯冲、连续配分裂、负面效果、护盾/加固/缓冲对靶场承伤。弹体护盾的真实拦截仍需同步对射场景。尚未穷尽所有两两或多层组合，也未完成真实手机性能与平衡压测。
