# ZMZ v0.20.1｜学长 main 最新 UI 合并与设置问题修复

**上游基线：** `main` @ `2c52b822d374`（包含 v0.19 沉浸式 HUD、v0.19.1 横屏与小地图适配、v0.20/0.20.1 设置改进与竞技场墙碰撞修正）。  
**目标分支：** `Zmz_dev`（**绝不更改 main**）；此前版本 v0.20.0。  
**交付渠道：** ZMZ 独立 APK 和 `zmz-game-v0.20.1-...` 游戏更新 Release。

## 1. 彻底修复游戏主页版本不同步

早期源码的网页大厅和游戏界面包含多处静态版本字符串，尤其在不同的首页与小游戏之间跳转时版本容易不一致。原生 APK 的版本号与在线下载的 Python 游戏版本号又是两件事。

- `game_source/build.py` 以唯一 `GAME_DISPLAY_VERSION="ZMZ v0.20.1"` 构建网页，将 `@@ZMZ_GAME_VERSION@@` 注入 **公共大厅、房间首页以及拆家战场页**。
- 更新游戏文件后，**完整停止并重新启动游戏服务**，页面从更新后的 Python 文件生成，三处都显示当前游戏版本。
- **APK 的 Android 原生版本**不能靠在线更新游戏文件更改。本次 ZMZ APK 版本名为 `0.20.1-ZMZ`，版本代码 11；原有安装包可能显示自己的宿主版本，此信息与游戏网页版本分离。
- 游戏服务已使用 `Cache-Control: no-store, no-cache, must-revalidate`，浏览器重新进入时不应加载旧版本 HTML。

## 2. 设置展开 24 种增益无法返回

将学长 main 的设置分组、直观地图预览、分项叠加上限及数字编辑整合进本分支，同时保留原有 24 类增益和实时已选数量。

- 默认折叠 `<details>` 增益选择；独立列表限定高度为 `min(45dvh,420px)`，列表自身可以垂直滑动。
- 增加醒目的 **「收起增益列表 · 返回其他设置 ↑」** 按钮，点击折叠列表并回滚到其他设置区域。
- 设置弹窗独立滚动、顶部关闭按钮固定可见。展开列表并不要求关闭房间或关闭整个设置。
- 24 类道具的勾选、全选/全不选/反选后即时刷新计数；选中数量动态以 `siegeBuffList.length` 计算，避免再次写死 16。

## 3. 整合学长 main 的功能

- 沉浸式拆家战斗 HUD：地图与房间菜单分开，操作面板按需展开，减小战斗画面遮挡。
- 持久小地图、整体摄像机和显示透明度设置；横屏空间下压缩操纵区以保留视野。
- **战术库存数字输入**：可直接输入弹跳、穿透等叠加数量，按照房主设定的每种道具上限校验。
- 房主可针对每类增益设置单发叠加上限（包含弹跳 20、穿透 10），另可调节建筑强度：原版、减伤 25%、减伤 45%；核心初始生命值不变。
- 采用 `main` 的房间设置数据结构、持久化和公共 JS，保留其它小游戏已适配的布局。
- 沿用主线音频选择菜单及音效按键，并保持 ZMZ 自动恢复已选背景音乐的逻辑。

## 4. ZMZ 独有内容不丢失

- 正向：螺旋、连续、推进、克隆 4 类；
- 负面：重重、湮灭、不稳定、屁屁 4 类，下一发强制生效，允许不同种同时触发；
- 旧版 16 类同时保留，总计 24 类；左右边界视为无限血量障碍，允许弹跳和命中特效。
- 服务器仍负责计算物理弹道与伤害、克隆炮台两回合持续与负面状态；不以仅客户端特效替代。
- 保留 `main` 之外 ZMZ 自己的 APK 包名及独立在线更新通道。

## 5. 测试

在原有 ZMZ v0.20.0 游戏回归基础上，加入 main v0.20/v0.20.1 的物理和设置验证。前端 Node 测试检查：24 类道具、设置回退、HUD、版本生成和音频恢复。可选 Playwright 测试来自学长 main（安装 Playwright Chromium 后运行，不作为 CI 的无头环境必跑项）。

只有 Actions 游戏构建和 Android 编译通过后，才发布 ZMZ v0.20.1 在线更新包。

### 更新提醒

1. APP 首页 **停止游戏服务**，点击检查更新并安装最新 ZMZ 游戏包；
2. 按提示重新启动游戏服务；再次打开大厅页面核对 `ZMZ v0.20.1`；
3. 如果使用旧 APK，Android 原生宿主版本可能仍显示旧号，**游戏网页版本**应显示最新号码；安装 v0.20.1 新 APK 才能同步原生版本。
4. 请先在小屏手机上验证「设置 → 展开增益 → 勾选 → 收起 → 返回其他设置 → 关闭设置」，然后再验证战斗中的新增炮弹效果。
