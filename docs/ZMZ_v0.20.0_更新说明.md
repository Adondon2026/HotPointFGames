# ZMZ v0.20.0｜拆家大战增益与物理系统升级

分支：`Zmz_dev`（**不修改 main**）；基线：v0.19.2；更新渠道：`zmz-game-v0.20.0-...`。

## 首页版本
- 网页公共大厅由旧的 **v0.18.2** 统一显示为 **ZMZ v0.20.0**。
- 局域网房间首页与拆家战场角标也显示 **ZMZ v0.20.0**。这些文字属于游戏 HTML，在线更新并重启游戏服务后即可变化；不同于 Android 宿主 APK 的版本名。
- ZMZ APK 的构建文件名升级为 `HotPointFGames-ZMZ-v0.20.0-debug.apk`，继续使用独立安装包名 `com.chuanmahjong.nearby.zmz.debug`。

## 四种正向增益
1. **螺旋弹** `spiral`：每个仿真时间步，把绕弹道的周期偏移叠加到主弹中心抛物线；层数越高，角速度越大，转动半径也略增。原有风力、地面和建筑碰撞继续参与。
2. **连续弹** `repeat`：同一角度、力度以 0.11 秒间隔追加若干弹体。叠加层数为 `n` 时总弹数 `1+n`，每弹基础伤害倍率为 `(1+0.35n)/(1+n)`；总伤害在理想全部命中时为 `1+0.35n` 倍，随层数递增，而单弹倍率递减。撞击由服务器对每个弹体单独结算。
3. **推进弹** `push`：命中范围内的可移动建筑获得沿来弹速度方向的初始冲量和有持续时间的加速度。层数增多时加速度更强、持续更久；障碍的不可破坏属性仍有效。
4. **克隆增益** `clone`：主弹落点产生克隆炮台，最多三个（一次叠加）；存在 **之后两次己方开炮**。下两次同角度、同力度自动发射 50% 威力的克隆弹；不消耗新库存，也不会再触发新克隆。为避免过量实体，双方克隆总量限制为六个。

## 四种负面增益
- **重重子弹** `heavy`：下一发子弹重力增至约 2.75 倍，射程明显缩短。
- **湮灭子弹** `vanish`：随飞行距离逐渐缩小碰撞半径、弹体视觉尺寸以及最终爆炸伤害，设有最低比例防止数值异常。
- **不稳定子弹** `wobble`：对原弹道增加 W 型正弦偏移。
- **屁屁子弹** `fart`：飞行时周期性向上喷推，并留下绿色屁屁气泡轨迹。

负面道具被子弹拾取后标记为**该玩家下次实际开炮强制生效**（本发不触发）；同一种负面最多保留一份，不因重复拾取再次叠加；不同种负面可同时生效，也能与所有正向增益组合。界面 HUD 显示「下发负面」提示。非房主和机器人模式仍遵循原有增益规则。

## 左右边界
原先主弹/分裂弹越过 `x<0` 或 `x>960` 会直接消失。v0.20.0 将两侧改为无限血量墙：普通命中会产生爆炸并触发适用效果，弹跳弹可消耗弹跳次数从左/右侧反射；连续弹、分裂弹和克隆弹也采用同样规则。不能用穿透弹穿墙。

## 向前兼容与回归
- 保留旧 16 种增益的名称、库存、战术储备/自动增益、炮台和核心瞬移行为。
- 新的总计 **24 种**增益均可由房主勾选允许/禁止（8 种新类型自动纳入）。
- 保留回合制、同步开炮及实时开炮共用的服务器物理计算，不会只修改客户端特效。
- 游戏数据仍在原目录内，新的待生效负面和克隆状态在重新开局时清零。旧房间状态缺少新字段时按空值兼容。
- 新增 `game_source/tests/test_siege_v20.py` 覆盖道具池、多类型叠加、负面下一发触发、螺旋/连续/推进/克隆、双边墙碰撞与同步开炮。
- 旧的 v0.19.0 / v0.19.1 / v0.19.2 历史文档保留；**此次一次性升级到 v0.20.0**。

## 更新方式
仅更新玩法和网页版本显示，可在已安装的 ZMZ 版 APP 首页检查更新、下载 `zmz-game-v0.20.0-...` 的游戏文件并按提示重启游戏服务，无需重装 APK。新版 APK 主要用于首次安装、统一宿主版本信息或完整交付。

> 服务器和 UI 的回归测试与 Android CI 构建通过后才视为可用；如在实际手机上发现问题，记录重现参数（模式、角度、力度和增益叠加数）。
