# ZMZ v0.24.2｜手机端增益设置改为翻页

**范围：** 仅 `Zmz_dev`，继承上游 `main @ 6aa32a7` 的拆家 v0.24、僵尸玩法和全部业务逻辑。此次不修改任何战斗物理与联机协议，不提交学长 `main`。

## 为什么不用滚动

手机上的 Android System WebView 曾出现：展开增益列表后，手指上下划却滚动下层设置。之前尝试 `touchmove` 控制内层 `scrollTop`，但在实际 realme 手机上仍有异常。为回避系统 WebView 的嵌套滚动差异，**本版删除列表滑动和手势转发逻辑，改为显式点击分页按钮。**

## 交互设计

- 展开「增益种类与叠加上限」后，弹窗自动进入**专注式屏内分页**，隐藏无关的房主设置项，显示顶部关闭按钮。
- 原有的 26 项增益默认分为 **3 页：9、9、8**，底部有「上一页」「1 / 2 / 3」「下一页」按钮及第 N / 总页数提示。矮屏幕和横屏将根据**实际可用区域高度**缩小每页条目数；此时页数可能增加，页码仍最多并排显示 3 个。
- 增益选项不发生页面滚动；切换页面只设置 CSS 显示/隐藏状态，所有 26 个复选框始终在 DOM 内。全选、全不选、反选、各分类全选/取消、预设的保存/加载和服务器房间设置保存仍针对全部道具，而非只对当前页生效。
- 底部保留「收起增益设置 · 返回其他选项」按钮；点击后恢复完整设置界面和打开前的滚动位置。
- 原有增益预设功能通过分页底部的「预设」按钮进入独立预设管理视图，点击「返回增益」回到分页，不丢失其他页勾选。
- 单页总高度受屏幕 `dvh` 约束，不依赖嵌套滚动。脚本逐页验证 `scrollHeight <= clientHeight`，不合适则减少单页项目数，以确保底部操作可见。
- 此 UI 修改属于网页游戏文件，也可以通过 ZMZ 在线游戏更新安装；同时出品与版本同步的 v0.24.2 独立 APK。

## 回归

`game_source/tests/test_zmz_webview_scroll.js` 验证 26 项/3 页、正常竖屏 9/9/8、窄矮屏自适应、跨页勾选不丢失、无上下滑动、预设入口和收起返回，配合已有上游 v0.24 Python/Node/Playwright 测试及 Android Gradle 单测。

**安装后实测重点：** 在手机 APP 创建房间 → 设置 → 增益种类与叠加上限 → 点击 1/2/3 翻页、跨页勾选 → 返回其他设置。无须上下划动。
