# ZMZ v0.20.2｜拆家大战物理与交互修复

**目标分支：** `Zmz_dev`。继续继承学长 `main` 中的沉浸式 HUD、横竖屏布局、数字叠加上限、房间设置与其他小游戏，绝不修改 `main`。

## 修复内容

### 1. 负面增益明确显示
- 自己及对手的 HUD 玩家区域中增加独立的红色「⚠ 下一发：……」状态；原普通增益说明在新版 HUD 中被 CSS 隐藏，本次绕开这个隐藏元素。
- 本机视角另显示「⚠ 下一发强制生效：……」，发射瞬间切换为「⚠ 本发负面效果：……」，直至本次射击结束。
- 负面状态仍由服务端 authoritative `negativePending` 管理，不计入可选库存；拾取后下一发强制生效，同种不叠加，不同种能同时生效。

### 2. 分裂、连续、其他增益组合
- **每个连续弹都继承本发已选攻击增益**，其中包含分裂：如果同时选择连续弹+分裂弹，则主弹与每枚连续弹分别在空中生成分裂子弹。
- 所有实际命中的主弹、连续弹、分裂子弹都会使用本发的威力、穿透、弹跳、黑洞、落物、推进和克隆配置。
- 每枚普通子弹命中（含连续/分裂）均可生成与当前克隆层数对应的克隆炮台，每个克隆保留后续 2 回合、以 50% 威力发射。**已有克隆发射的回声弹不再递归生成克隆**，避免无限复制。
- 分裂子弹保留原版降低单枚基础伤害的平衡设定；连续弹采用原有单枚伤害递减、总伤递增公式。
- 炮台/核心瞬移属于单次消耗的**全局位置变更**，仍在本次射击结束时统一结算一次，不在每枚分裂子弹到达不同落点时反复切换炮台位置。

### 3. 负面弹重新调整
- **不稳定子弹**：不再沿 W 型飞行；发射瞬间随机产生 ±14°～24° 的角度偏差，然后以新角度沿正常重力弹道飞行。临近 5°/175° 极限时自动选择可用方向。实际角度与偏移写入回放事件。
- **重重子弹**：所受重力加速度从原来的 2.75 倍提高至 6.5 倍，明显更容易提前坠落；与其他弹道增益兼容。
- 湮灭与屁屁子弹原有状态保留，可与新的角度偏移组合。

### 4. 推进弹：低伤害与恒速飞行
- 直接破坏伤害降低到正常弹的约 14%；仍可与强力弹等独立乘法组合。
- 实际击中的可移动木、石建筑块（包括可被释放的固定建筑）会沿碰撞时该颗弹的**实际速度方向**，以约 90% 命中速度（限幅 220～610 世界单位/秒）恒速前进。
- **每层延长 2 秒**：1 层=2 秒、2 层=4 秒、3 层=6 秒，重复命中继续累计剩余推动时间。推动期间不再不断加速、也不被额外重力拉偏；推动结束恢复正常重力和阻尼。
- 仍遵循固体边界与物块碰撞，遇不可穿透障碍可能提前受阻；核心和永久平台不强制推进。

### 5. 被毁支撑导致炮台/核心浮空
- 瞬移后的炮台启动独立的重力下落判定：根据当前实际存活的建筑和地形计算脚下最近支撑面。
- 如果原本托举炮台的建筑 HP 归零，炮台在后续 60Hz 物理步中下落到下一块建筑或地面，而不是停留在旧高度。
- 瞬移后的核心仍作为有重力的碰撞物块，支撑物被毁后继续参与原有物块物理积分。
- 原本设计为浮空移动的战场特殊平台不被无条件强行落地，以免破坏既有浮岛场景。

## 验证
- 原有 v0.20.0、v0.20.1 和学长 main 上游拆家/多人/机器人/同步模拟测试保持运行。
- 新增 v0.20.2 物理回归：一次性角度偏移、6.5x 重力、推进 2 秒/层可累加、固定建筑释放、连续+分裂+克隆全弹继承、炮台失去支撑后下落、核心失去支撑后下落。
- 新增负面 HUD 的 Node/JavaScript 结构与语法检查。
- 游戏版本来自 `game_source/build.py` 统一注入，在线更新后重启游戏服务将显示 **ZMZ v0.20.2**。
- ZMZ APK 使用独立包名和 `zmz-game-v0.20.2-*` 游戏发布通道，与学长 main 分开。

## 更新步骤
先在当前 ZMZ APP 中检查在线游戏更新并下载安装，**停止、重新启动游戏服务**后进入战场验证负面警示；若需要更新 Android 系统应用显示版本，安装 v0.20.2-ZMZ 独立 APK。
