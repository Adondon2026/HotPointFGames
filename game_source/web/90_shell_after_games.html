怎么玩

骗子牌：暗出 1～3 张，下一家继续或质疑。目标牌和 Joker 算真话。

大话骰：叫法表示全场“至少”有相应数量。开你只在实际数量少于叫数时成功；相等或更多都算上一家叫法成立。抓准则要求实际数量刚好相等。开启1点万能时，叫2～6点会把1点计入；叫1点只统计1点。

你画我猜：画家从 3 个中文题目中选一个；不能写字、数字或拼音。猜中越早得分越高，画家也会得分。每个人轮流作画。

斗地主：1～3 名真人，系统自动补足 3 家。每人 17 张，3 张底牌归地主；按 1～3 分轮流叫地主。地主先出，支持常见完整牌型。

四川麻将：2～4 人，使用万、筒、条共 108 张牌。先换三张同花色牌，再定缺；有缺门牌时必须优先打出。支持碰、明杠、暗杠、补杠、自摸与点炮，采用血战到底和简化番分。
