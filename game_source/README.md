# HotPointFGames Lite · 斗地主牌桌体验版

Windows：解压后双击 `START_GAME.bat`，浏览器自动打开游戏厅；也可 `python run_preview.py`。Python 3.10+，无需第三方库。手机房主使用 Android v1.2 运行器导入 `dist/game_hall_lan_v6_2.py`（或 .txt），关闭 APP 再重新打开。手机本机单人游戏不需要开启热点。

## 玩法
- 选游戏 → 单人开局（自动添加所需机器人），或在大厅手动添加/移除机器人。
- 斗地主固定三家，空位自动补足；骗子牌、大话骰、四川麻将 2–4 座位，真人局不自动补机器人。单人川麻默认加 1 个机器人，也可手动加至 3 个。
- 你画我猜：纯真人轮流作画；添加一个机器人后为独立猜图练习模式，机器人从 12 幅内置简笔画出题，所有真人猜题，每轮 3 题，不支持机器人理解真人绘画。
- 每种游戏在选中后有自己的规则与设置。斗地主和川麻当前固定玩法，不额外虚构设置。
- 账户积分：纯真人好友局获胜 +3，失败 0；含机器人的对局只统计练习场次与胜率，积分为 0。游戏原始分单独展示，不计入账户积分。已有历史积分保留（旧记录无法可靠区分是否含机器人）。并列最高分按现有游戏规则共同获胜，不另设平局状态。

## 斗地主牌桌
- 横竖屏使用不同空间布局，旋转保留选牌。底牌默认折叠，确定地主时展示一次。
- 每次叫分、出牌、不出、重新领出均记录，浏览器按顺序呈现；行动尚未呈现完成时暂不开放出牌。断线恢复直接同步最新桌面，可回看本局记录。
- 手机横竖屏、平板和桌面宽屏均已检查；真实手机仍需验证。

## 数据
`local_data/` 保存账户 SQLite 数据和房间状态。更新请保留原文件夹的 `local_data`，停止旧服务器后覆盖程序文件。导入 Android 版本会保留运行器私有数据（房间主动停止会清空）。

## 开发
`python build.py` 生成单文件；`python tests/smoke_test.py`、`python tests/test_lite.py`、`python tests/test_bots.py`、`python tests/test_table.py` 验证核心功能。机器人由服务端根据公开信息和自身手牌/骰子行动；无需网络或 AI 模型。用户仍需通过局域网连接才能与朋友联机。

## 斗地主竖屏智能两排
竖屏手牌较多自动两排，尽量不拆同点数与大小王；出牌后保留原行，剩余牌可舒适放入单排时合并。横屏继续单排，旋转保留选择。

## 四款游戏专属舞台

斗地主智能两排保留。骗子牌新增目标牌、牌背与翻牌舞台；大话骰用点阵骰子、叫数和近期叫数组织界面；四川麻将按玩家分牌河与副露、竖屏分组手牌、按合法操作显示响应；你画我猜保留画板比例，横屏工具与猜题区在侧边。三款桌游增加公开行动顺序播放与最近 512 条记录，原有规则、账户和积分不变。旧对局在升级前发生的行动无法补录。

## 状态与反馈强化

五款游戏区分当前行动权（亮绿）与刚完成的行动（金色），并在本方操作区持续标明任务。骗子牌、大话骰记录资源前后值；川麻新摸牌独立放在末尾、牌面使用深色文字；斗地主行动记录包含公开余牌数及倍数；猜图显示猜中和本题得分。历史存档缺少新事件字段时仍可运行。

新增测试：`python tests/test_feedback.py`（先运行 `python build.py`）。
