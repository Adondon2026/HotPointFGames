# HotPointFGames Lite · 本地预览

双击 `START_GAME.bat`；或在本目录打开终端执行 `python run_preview.py`。程序会启动服务器并打开默认浏览器。保持终端窗口开启，Ctrl+C 结束。

- 电脑：浏览器自动打开 http://127.0.0.1:8000/（端口占用时自动尝试 8001–8010）。
- 手机：与电脑连接同一个 Wi-Fi/热点，房主进入大厅后点击「邀请朋友」，选择正确的局域网 IP，手机扫码并在浏览器打开，注册/登录或游客加入。若 Windows 防火墙询问，允许专用网络访问。二维码是房间邀请，不是免密码登录凭据。
- 账户、积分及房间状态在 `local_data/`，不要删除该目录。账户 PIN 4–8 位，仅用于可信局域网；不建议复用其他密码或暴露公网。
- 积分：完整结束对局 +1，胜者额外 +2；斗地主农民胜则两名农民均为胜者；麻将和你画我猜按最高原始分（并列均胜）；中途退出/结束不计分；游客不计分。
- 开发：改 `parts/`、`web/` 后执行 `python build.py`，再启动预览。生成 `dist/game_hall_lan_v6_2.py` 可导入 Android 运行器 v1.2。账户数据库存于运行游戏服务器的设备，同一房主可累计，跨房主不同步。
- 不需要 pip、Node、Android SDK 或互联网。需要本机 Python 3.9+（建议 3.13）。
