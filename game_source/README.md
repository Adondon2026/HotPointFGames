# HotPointFGames Lite · v0.15 浮空战场与建造炮弹

Windows：解压后双击 `START_GAME.bat`，浏览器自动打开游戏厅；也可 `python run_preview.py`。Python 3.10+，无需第三方库。手机房主使用 Android 1.3 检查更新，或运行器手动导入 `dist/game_hall_lan_v6_2.py`（或 .txt），关闭 APP 再重新打开。手机本机单人游戏不需要开启热点。

## 玩法
- v0.15：新增浮岛对决、浮空夹击，炮台与堡垒独立周期升降；随机道具数量×1/×2/×3/×5；新增弹跳弹、木块生成、石块生成，炮弹有效终止碰撞后按层数连续空投可碰撞建筑，双方核心均可能受伤。修复保持单份。
- v0.14：所有玩家可拖动战场观察全局，右上角小地图可点击或拖动定位，回炮台恢复瞄准；空中城堡及移动屏障加入实际弹性顶板，取消全局视野道具（旧库存转换为强力弹）。
- v0.13：拆家大战支持自动增益和战术储备模式，储备模式可自由选择本轮使用的增益与层数；新增越顶对决、空中城堡、移动屏障三套空间布局，随机战场包含九套布置。
- v0.12：你画我猜竖屏大画布、猜词自动换行和纵向滚动；拆家大战新增后向瞄准、修复、随机道具阵型及延迟刷新，分裂弹采用真实独立弹道，炮位与风力加强。
- 扫码进入公共大厅，游客或账号均可创建/加入房间，房主在房间内选择游戏并直接开始。七款游戏可独立并行，结束后返回原房间。
- 拆家大战：双人炮击或机器人练习，十一套可指定或随机的战场布置、三种预设堡垒、移动道具及全局视野、分裂弹、穿透弹、缓冲层、可选风力，默认无限炮弹，道具 0–25 个。同类增益累积次数，不同类自动组合；普通弹削弱，强化弹突破。暂不计入积分。
- 选游戏 → 单人开局（自动添加所需机器人），或在大厅手动添加/移除机器人。
- 斗地主固定三家，空位自动补足；骗子牌、大话骰、四川麻将 2–4 座位，真人局不自动补机器人。单人川麻默认加 1 个机器人，也可手动加至 3 个。
- 你画我猜：纯真人轮流作画；添加一个机器人后为独立猜图练习模式，机器人从 12 幅内置简笔画出题，所有真人猜题，每轮 3 题，不支持机器人理解真人绘画。
- 每种游戏在选中后有自己的规则与设置。斗地主和川麻当前固定玩法，不额外虚构设置。
- 账户积分：纯真人好友局获胜 +3，失败 0；含机器人的对局只统计练习场次与胜率，积分为 0。游戏原始分单独展示，不计入账户积分。已有历史积分保留（旧记录无法可靠区分是否含机器人）。并列最高分按现有游戏规则共同获胜，不另设平局状态。

## 斗地主牌桌
- 横竖屏使用不同空间布局，旋转保留选牌。底牌默认折叠，确定地主时展示一次。
- 每次叫分、出牌、不出、重新领出均记录，浏览器按顺序呈现；行动尚未呈现完成时暂不开放出牌。断线恢复直接同步最新桌面，可回看本局记录。
- 手机横竖屏、平板和桌面宽屏均已检查；真实手机仍需验证。

## 数据
`local_data/` 保存账户 SQLite 数据和房间状态。更新请保留原文件夹的 `local_data`，停止旧服务器后覆盖程序文件。导入 Android 版本会保留运行器私有数据（房间主动停止会清空）。

## 开发
`python build.py` 生成单文件；`python tests/smoke_test.py`、`python tests/test_lite.py`、`python tests/test_bots.py`、`python tests/test_table.py` 验证核心功能。机器人由服务端根据公开信息和自身手牌/骰子行动；无需网络或 AI 模型。用户仍需通过局域网连接才能与朋友联机。

## 斗地主竖屏智能两排
竖屏手牌较多自动两排，尽量不拆同点数与大小王；出牌后保留原行，剩余牌可舒适放入单排时合并。横屏继续单排，旋转保留选择。

## 四款游戏专属舞台

斗地主智能两排保留。骗子牌新增目标牌、牌背与翻牌舞台；大话骰用点阵骰子、叫数和近期叫数组织界面；四川麻将按玩家分牌河与副露、竖屏分组手牌、按合法操作显示响应；你画我猜保留画板比例，横屏工具与猜题区在侧边。三款桌游增加公开行动顺序播放与最近 512 条记录，原有规则、账户和积分不变。旧对局在升级前发生的行动无法补录。

## 状态与反馈强化

五款游戏区分当前行动权（亮绿）与刚完成的行动（金色），并在本方操作区持续标明任务。骗子牌、大话骰记录资源前后值；川麻新摸牌独立放在末尾、牌面使用深色文字；斗地主行动记录包含公开余牌数及倍数；猜图显示猜中和本题得分。历史存档缺少新事件字段时仍可运行。

新增测试：`python tests/test_feedback.py`（先运行 `python build.py`）。

## 川麻四方牌桌

自己固定下方，四人局依次分布于右、上、左，三人局左右各一家，两人局对坐。牌河、玩家信息和副露各自归位；不再使用四宫格卡片。手牌宽牌单排，窄屏可左右滑动、横屏空间足够时完整显示，新摸牌独立在右侧并自动进入视野，点击抬牌并显示放大预览，确认按钮出牌。当前行动以座位小标记、中央方向箭头和本方操作区表达，分数变化只在对应玩家处短暂显示。长牌河在各自座位内滚动，最新弃牌自动可见；记录入口可以回看公开行动。规则、机器人和积分不变。

宽牌手牌：竖屏牌宽 42–44px，横屏约 44–46px；仅手牌区域横向滚动，轮询和选牌保留浏览位置，新摸牌时定位到末尾，鼠标拖动和手机原生滑动不触发选牌。

## 军棋（双人暗棋）

新增第六款游戏，规则以用户提供的 ArmyChessPython v0.6.1 / RULES_FROZEN_v1.1.md 为基准。原 topology.py、rules.py、game_state.py 存放在 parts/army/，构建时嵌入独立命名空间，保持单文件标准库运行。支持合法随机布阵、交换棋子、确认布阵、两种胜利方式、先手、山界及私人标记设置、合法落点与上一步路径、认输、求和、悔棋和结束后复盘。单人规则型机器人不是高水平 AI，接受悔棋、拒绝求和；纯真人局计入既有好友积分。布阵仅显示己方半场，开局展示全棋盘；手机横屏为左右对阵。原独立程序的聊天与独立历史统计不移植；复盘支持逐步前后查看和三种暗棋显示模式。

测试：`python tests/test_army.py`（先执行 `python build.py`）。
